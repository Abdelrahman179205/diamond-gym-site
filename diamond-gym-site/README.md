# Diamond Gym Egypt Website — Concept v0.1

A React + Vite concept site for Diamond Gym Egypt.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```
